Homebox-Installation für Logge

Sammelinstaller mit Koordinatenliste (ZIP). Auf der Homebox als Besitzer des Benutzerdienstes ausführen, sobald die ausgewählten Standorte aufgebaut sind. Für andere Standorte beide --sites-Listen anpassen. Für alle acht Standorte --sites K19,K25 in beiden Befehlen weglassen.

set -eu
ausbau_dir="$(mktemp -d)"
cd "$ausbau_dir"
curl -fsSLo erebor-schlussausbau.zip https://campus.logge.top/assets/erebor-schlussausbau.zip
echo '50bea1ee880d61048a9315d0520871d1a04d0d72daa5dafd5cad043f65cdea94  erebor-schlussausbau.zip' | sha256sum -c -
unzip -q erebor-schlussausbau.zip
python3 install.py check --sites K19,K25
python3 install.py install --sites K19,K25
